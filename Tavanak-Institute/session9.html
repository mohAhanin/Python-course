🔁 یادآوری کوتاه از جلسه‌ی قبل

توی جلسه‌ی قبل با حلقه‌ی for، range()، break و لیست‌های تودرتو کار کردیم. حالا که دیگه کدهای طولانی‌تری می‌نویسیم، وقتشه یاد بگیریم چطور کدها رو مرتب و قابل استفاده‌ی مجدد بنویسیم. 🎯

🧩 تابع (Function) چیه؟

تابع یعنی یک تکه کد که بهش اسم می‌دیم و هر وقت لازم داشتیم، فقط با صدا زدن اسمش اجراش می‌کنیم. مثل یک دستگاه که یک کار مشخص انجام می‌ده: ورودی می‌گیره، کارش رو می‌کنه و (اگه لازم باشه) نتیجه رو برمی‌گردونه.

🎯 چرا تابع؟ فرض کن یک کد ۵ خطی داری و لازمه ۱۰ جای مختلف برنامه ازش استفاده کنی. به‌جای کپی کردن ۱۰ باره‌ی اون ۵ خط، یک بار تابعش رو می‌نویسی و ۱۰ بار صداش می‌زنی! اگه هم خواستی تغییرش بدی، فقط یک جا رو عوض می‌کنی.

تا الان خودت هم از تابع استفاده کردی: print()، input()، len() و int() همه تابع‌های آماده‌ی پایتون هستن. حالا یاد می‌گیریم تابع‌های خودمون رو بسازیم!

🛠️ تعریف و صدا زدن تابع

برای تعریف تابع از کلمه‌ی def (مخفف define به معنی «تعریف کن») استفاده می‌کنیم.

کدdef niyayesh(): print("hello!") niyayesh()
خروجیhello!

🔍 ساختار تابع

  • def کلمه‌ی کلیدی برای ساخت تابعه.
  • بعدش اسم تابع میاد (niyayesh) و بعد پرانتز () و دونقطه :
  • خطوط داخل تابع باید تورفتگی (indent) داشته باشن، درست مثل if و حلقه‌ها.
  • فقط تعریف کردن تابع کافی نیست! برای اجرا شدنش باید با اسمش و پرانتز صداش بزنی: niyayesh()
⚠️ خطای رایج: اگه تابع رو تعریف کنی ولی هیچ‌وقت صداش نزنی، هیچ اتفاقی نمی‌افته! تعریف تابع مثل نوشتن دستور پخت یک غذاست؛ تا آشپزی نکنی، غذایی آماده نمی‌شه.

📥 تابع با پارامتر

می‌تونیم به تابع یک ورودی بدیم تا باهاش کار کنه. به این ورودی پارامتر (Parameter) می‌گیم.

کدdef name(name): print("hello", name) name("niyayesh")
خروجیhello niyayesh

هر بار که تابع رو با یک مقدار متفاوت صدا بزنیم، نتیجه هم متفاوته:

کدname("ali") name("sara")
خروجیhello ali hello sara

🚫 اگه پارامتر رو ندیم چی می‌شه؟

کدname() # بدون دادن مقدار!
خطاTypeError: name() missing 1 required positional argument: 'name'

پایتون می‌گه: «این تابع یک ورودی لازم داره ولی تو چیزی ندادی!» پس همیشه باید به تعداد پارامترهایی که تابع می‌خواد، مقدار بدیم.

💡 اصطلاح: اسمی که موقع تعریف تابع داخل پرانتز می‌نویسیم، «پارامتر» نام داره (name توی def name(name)). مقداری که موقع صدا زدن می‌دیم، «آرگومان» نام داره ("niyayesh").

📦 تابع با چند پارامتر

یک تابع می‌تونه چند ورودی داشته باشه؛ فقط کافیه با کاما از هم جداشون کنیم. ترتیب مقدارها موقع صدا زدن هم مهمه!

کدdef greet(name, age): print("hello", name) print("u r ", age, " years old") greet("ali", 3)
خروجیhello ali u r 3 years old
💡 "ali" به پارامتر اول (name) و 3 به پارامتر دوم (age) می‌رسه. اگه جاشون رو عوض کنیم، نتیجه هم عوض می‌شه!

🎁 خروجی دادن با return

گاهی نمی‌خوایم تابع فقط چیزی چاپ کنه؛ می‌خوایم یک نتیجه به ما پس بده تا بتونیم بعداً ازش استفاده کنیم. برای این کار از return استفاده می‌کنیم.

کدdef sum(a, b): return a + b sum(3, 6) print(sum(3, 9))
خروجی12

🔍 چرا فقط یک خروجی چاپ شد؟

  • خط sum(3, 6) نتیجه‌ی ۹ رو برمی‌گردونه، ولی چون هیچ‌جا چاپش نکردیم یا داخل متغیری نریختیمش، همون‌جا گم می‌شه.
  • خط print(sum(3, 9)) نتیجه‌ی ۱۲ رو برگردوند و print هم اون رو چاپ کرد.

💾 ذخیره‌ی نتیجه داخل متغیر

کدresult = sum(3, 6) print(result) print(result * 2)
خروجی9 18

⚖️ فرق print و return

printreturn
کارشمقدار رو فقط روی صفحه نشون می‌دهمقدار رو به جایی که تابع صدا زده شده پس می‌ده
می‌تونیم بعداً ازش استفاده کنیم؟نهبله (مثلاً داخل متغیر یا محاسبه)
مثال تشبیهیبلند خوندن جوابنوشتن جواب روی کاغذ و دادن به کسی که پرسیده
⚠️ نکته‌ی مهم: بعد از اجرای return، تابع تموم می‌شه و خطوط بعد از اون اجرا نمی‌شن.
⚠️ اسم‌گذاری: اسم sum قبلاً یک تابع آماده‌ی پایتونه (که مجموع اعضای یک لیست رو حساب می‌کنه). اگه تابع خودمون رو هم sum بنامیم، تابع اصلی پایتون رو «بازنویسی» می‌کنیم و ممکنه بعداً به مشکل بخوریم. بهتره اسم‌هایی مثل add یا my_sum انتخاب کنیم.

⌨️ تابع‌هایی که با کاربر ارتباط می‌گیرن

داخل تابع می‌تونیم از input() هم استفاده کنیم:

کدdef get_num(): num = int(input("number?")) print(num) get_num()
خروجی نمونهnumber?8 8
💡 این تابع عدد رو چاپ می‌کنه، ولی پس نمی‌ده. اگه بخوایم بتونیم بعداً از اون عدد استفاده کنیم، بهتره به‌جای print(num) بنویسیم return num.

🧺 تابع که روی لیست کار می‌کنه

می‌تونیم یک لیست رو هم به‌عنوان پارامتر به تابع بدیم و داخل تابع تغییرش بدیم. این مثال یک لیست خالی رو با اعدادی که از کاربر می‌گیره، پر می‌کنه:

کدdef listporkon(l, size): length = size for i in range(length): a = int(input("number?")) l.append(a) print(l) a = [] listporkon(a, 4)
خروجی نمونهnumber?5 number?2 number?8 number?1 [5, 2, 8, 1]

🔍 این کد چیکار می‌کنه؟

  • تابع دو ورودی می‌گیره: یک لیست (l) و تعداد اعدادی که باید پر بشه (size).
  • با یک حلقه‌ی for به تعداد size بار از کاربر عدد می‌گیره و به لیست اضافه می‌کنه.
  • در پایان لیست پر شده رو چاپ می‌کنه.
  • بیرون از تابع، یک لیست خالی به اسم a ساختیم و به تابع دادیمش؛ بعد از اجرا، لیست a هم پر شده، چون تابع روی همون لیست کار کرده.
🎯 ترکیب مفاهیم: این تابع کوچیک همه‌ی چیزهایی که یاد گرفتی رو با هم داره: تابع، پارامتر، حلقه‌ی for، range، input، تبدیل نوع داده و append!
