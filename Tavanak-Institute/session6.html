لیست‌ها (Lists) در پایتون

جزوه‌ی درسی

🔁 یادآوری کوتاه از جلسه‌ی قبل

توی جلسه‌ی قبل با if، elif و else یاد گرفتیم چطور برنامه بر اساس یک شرط تصمیم بگیره. مثلاً:
مرور سریعa = 12 b = 12 if(a==b): print("umbrella")
خروجیumbrella

توی این جلسه یک ابزار جدید و خیلی قدرتمند یاد می‌گیریم: لیست (List) — یعنی به‌جای اینکه هر مقدار رو توی یک متغیر جدا نگه داریم، همه رو با هم توی یک جعبه‌ی بزرگ بذاریم. 🎯

📦 لیست (List) چیه؟

لیست یک ظرف واحده که می‌تونه چند مقدار رو با هم نگه داره — حتی اگه اون مقدارها از نوع‌های مختلف باشن! برخلاف متغیرهای معمولی که فقط یک مقدار داشتن، لیست می‌تونه عدد، رشته، بولی و ... رو با هم نگه داره.

کدa = [1, 2, "sara", "c", True] print(a)
خروجی[1, 2, 'sara', 'c', True]

می‌بینی که توی یک لیست، هم عدد صحیح (1, 2) هم رشته ("sara", "c") و هم مقدار بولی (True) کنار هم قرار گرفتن. این یکی از نقاط قوت پایتونه!

🎯 کجا به کارمون میاد؟ لیست دقیقاً مثل یک لیست خرید یا یک صف موسیقیه: می‌تونی هر چقدر خواستی بهش آیتم اضافه کنی و به‌جای ده‌ها متغیر جدا، همه رو با هم مدیریت کنی.

🔢 اندیس‌گذاری در لیست (Indexing)

دقیقاً مثل رشته‌ها، توی لیست هم هر عضو یک اندیس (جایگاه) داره که از ۰ شروع می‌شه. علاوه بر این، پایتون به ما اجازه می‌ده از اندیس‌های منفی هم برای شمردن از انتهای لیست استفاده کنیم.

کدa = [1, 2, "sara", "c", True] print(a[-1]) print(a[-2]) print(a[0])
خروجیTrue c 1

💡 نکته‌ی طلایی: اندیس -1 همیشه به آخرین عضو لیست اشاره می‌کنه، -2 به یکی‌مونده‌به‌آخر، و همین‌طور به عقب برمی‌گرده. دیگه لازم نیست طول لیست رو بشماری تا به آخرش برسی!

✂️ برش لیست (Slicing)

می‌تونیم مثل رشته‌ها، یک تکه از لیست رو هم جدا کنیم.

کدa = [1, 2, "sara", "c", True, "ava", " bardia", 3.14] print(a[1:]) # از اندیس 1 تا آخر print(a[2:]) # از اندیس 2 تا آخر print(a[:4]) # از اول تا قبل از اندیس 4 print(a[1:4]) # از اندیس 1 تا قبل از اندیس 4
خروجی[2, 'sara', 'c', True, 'ava', ' bardia', 3.14] ['sara', 'c', True, 'ava', ' bardia', 3.14] [1, 2, 'sara', 'c'] [2, 'sara', 'c']
نوشتارمعنی
a[n:]از اندیس n تا انتهای لیست
a[:n]از ابتدای لیست تا قبل از اندیس n
a[m:n]از اندیس m تا قبل از اندیس n
⚠️ یادت باشه: درست مثل رشته‌ها، توی برش [m:n] عضوِ اندیس n جزو نتیجه نیست!

➕ اضافه کردن عضو با ()append

برای اضافه کردن یک عضو جدید به انتهای لیست، از تابع append() استفاده می‌کنیم.

کدa = [1, 2, "sara", "c", True, "ava", " bardia", 3.14] b = a[1:4] print(b) b.append("taha") print(b)
خروجی[2, 'sara', 'c'] [2, 'sara', 'c', 'taha']

می‌بینی که b اول با برش a[1:4] ساخته شد، و بعد با append("taha") یک عضو جدید بهش اضافه کردیم.

🔗 ترکیب لیست با if

می‌تونیم از if برای بررسی یک عضو خاص از لیست هم استفاده کنیم:

کدif(b[0]==1): b.append(1) print(b)
خروجی (وقتی b[0] برابر 2 است)[2, 'sara', 'c', 'taha']

چون عضو اول لیست b برابر با 2 بود نه 1، شرط False شد و چیزی اضافه نشد. اگه عضو اول 1 بود، یک 1 دیگه هم به انتهای لیست اضافه می‌شد.

🎯 جمع‌بندی این بخش: لیست‌ها + اندیس‌گذاری + برش + append() + if با هم ترکیب می‌شن تا بتونی داده‌های واقعی رو مدیریت کنی — دقیقاً همون کاری که برنامه‌های واقعی انجام می‌دن!

✅ پاسخ تمرین‌های جلسه پنجم

این‌ها نمونه‌پاسخ‌های تکلیف جلسه‌ی قبل هستن که با هم توی کلاس حل کردیم:

۱. رمز عبور ساده
correct_password = "python123" password = input("Enter password: ") if password == correct_password: print("Access granted") else: print("Wrong password")
۲. نمره‌ی درسی
grade = int(input("Enter your grade: ")) if grade > 18: print("Excellent") elif grade >= 10: print("Pass") else: print("Fail")
۳. رده‌سنی سینما
age = int(input("Enter your age: ")) if age < 13: print("Child") elif age <= 17: print("Teen") else: print("Adult")
۴. بزرگ‌ترین عدد بین دو عدد
n1 = int(input("Enter first number: ")) n2 = int(input("Enter second number: ")) if n1 == n2: print("Equal") elif n1 > n2: print("First is bigger") else: print("Second is bigger")
۵. if تودرتو
age = int(input("Enter your age: ")) if age == 14: height = int(input("How tall are you? ")) if height > 160: print("You are the tallest in class!")
۶. چالش اضافه ⭐
n = int(input("Enter a number: ")) if n % 2 == 0 and n % 3 == 0: print("Divisible by both") elif n % 2 == 0: print("Only even") elif n % 3 == 0: print("Only divisible by 3") else: print("Neither")

📓 تکلیف جلسه ششم

این هفته تکلیف بیشتره و بخشی از تمرین‌ها ترکیبی از همه‌ی جلسات قبل هستن (عملگرهای حسابی، مقایسه‌ای، منطقی، رشته‌ها، تبدیل نوع داده، و if). سعی کن همه رو کامل حل کنی. 💪

بخش ۱ — تمرین‌های مخصوص لیست

۱. لیست میوه‌ها

یک لیست از ۵ میوه‌ی مورد علاقه‌ات بساز و کل لیست رو چاپ کن. بعد میوه‌ی اول و میوه‌ی آخر رو با اندیس‌گذاری (یکی با اندیس مثبت و یکی با اندیس منفی) چاپ کن.

لیست‌هااندیس‌گذاری
۲. برش لیست

یک لیست با ۸ عضو مختلف (عدد، رشته و بولی با هم) بساز. سه عضو وسط لیست رو با slicing جدا کن و چاپ کن.

لیست‌هابرش
۳. لیست در حال رشد

یک لیست خالی از اسامی دوستانت بساز ([]) و با append() سه اسم بهش اضافه کن. بعد از هر append، لیست رو چاپ کن تا ببینی چطور بزرگ می‌شه.

لیست‌هاappend

بخش ۲ — تمرین‌های ترکیبی (مرور همه‌ی جلسات)

۴. لیست نمرات و بررسی اولین نمره

یک لیست از ۵ نمره‌ی درسی (عدد) بساز. با if بررسی کن که آیا اولین نمره‌ی لیست (list[0]) بالای ۱۵ هست یا نه، و پیام مناسب چاپ کن.

لیست‌هاifمقایسه
۵. رشته به لیست حروف

یک رشته (مثل اسمت) بگیر و با اندیس‌گذاری، حرف اول و حرف آخرش رو داخل یک لیست جدید بریز (مثلاً letters = [name[0], name[-1]]) و لیست رو چاپ کن.

رشته‌هالیست‌هااندیس‌گذاری
۶. ماشین‌حساب لیستی

یک لیست دو عضوی از دو عدد که کاربر با input() و int() وارد می‌کنه بساز (مثلاً numbers = [n1, n2]). حاصل جمع، تفریق و ضرب numbers[0] و numbers[1] رو چاپ کن.

لیست‌هاعملگرهای حسابیتبدیل نوع داده
۷. بررسی عضویت با شرط ترکیبی

یک لیست از سه رنگ مورد علاقه بساز. با عملگر or بررسی کن که آیا عضو اول لیست برابر "blue" است یا عضو دوم برابر "red"، و نتیجه رو با if چاپ کن.

لیست‌هامنطقیif
۸. کارت اطلاعات کامل

یک لیست به نام info بساز که این ترتیب رو داشته باشه: [اسم (رشته)، سن (عدد)، قد (اعشاری)، آیا دانش‌آموزه (بولی)]. سپس:

  • با print() و اندیس‌گذاری، یک جمله‌ی کامل معرفی با f-string بساز.
  • با if بررسی کن اگه سن (info[1]) بالای ۱۳ بود، به لیست رشته‌ی "teenager" رو با append() اضافه کن.
  • لیست نهایی رو چاپ کن.
لیست‌هارشته‌هاifappendf-string
۹. سوال

یک لیست خالی به اسم even_or_odd بساز. یک عدد از کاربر بگیر و با % بررسی کن زوجه یا فرد. اگه زوج بود، رشته‌ی "even" رو با append() به لیست اضافه کن، وگرنه "odd" رو. در پایان لیست رو چاپ کن. (راهنمایی: این تمرین ترکیبیه از جلسه‌ی ۲، ۵ و ۶!)

بخش ۳🎯

۱۰. لیست تولد

یک لیست به نام birthday بساز که سه عدد داخلش باشه: روز، ماه، سال تولدت (مثلاً [14, 6, 2011]). با اندیس‌گذاری و f-string یک جمله چاپ کن که تاریخ تولدت رو نشون بده.

لیست‌هااندیس‌گذاریf-string
۱۱. طول لیست با ()len

یک لیست از حداقل ۶ کتاب یا فیلم مورد علاقه بساز. با len() تعداد اعضای لیست رو چاپ کن. بعد با if بررسی کن که آیا تعداد اعضا بیشتر از ۵ هست یا نه.

لیست‌هاlenif
۱۲. برش دوطرفه

یک لیست ۱۰ عضوی از اعداد ۱ تا ۱۰ بساز (می‌تونی دستی تایپشون کنی). با slicing سه عضو اول رو جدا کن، سه عضو آخر رو هم با اندیس منفی جدا کن، و هر دو رو چاپ کن.

لیست‌هابرشاندیس منفی
۱۳. append ترکیبی با ورودی کاربر

یک لیست خالی به نام shopping_list بساز. سه بار از کاربر با input() اسم یک خوراکی بگیر و هر بار با append() به لیست اضافه کن. در پایان کل لیست خرید رو چاپ کن.

لیست‌هاinputappend
۱۴. مقایسه‌ی دو عضو از لیست

یک لیست دو عددی از کاربر بساز (هر دو عدد با input() و int() گرفته بشن). با if/elif/else بگو کدوم عضو لیست بزرگ‌تره یا با هم برابرن.

لیست‌هامقایسهif/elif/else
۱۵. چالش نهایی — دفترچه‌ی کوچک نمرات ⭐⭐⭐

یک لیست خالی به اسم grades بساز. سه بار از کاربر یک نمره (عدد) بگیر و با append() به لیست اضافه کن. بعد از هر نمره، با if بررسی کن که آیا اون نمره بالای ۱۰ هست یا نه و پیام «قبول» یا «مردود» چاپ کن. در پایان کل لیست نمرات رو نمایش بده.
