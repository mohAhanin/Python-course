عبارت‌های شرطی: if، elif و else

جزوه‌ی درسی

🔁 یادآوری کوتاه از جلسه‌ی قبل

یادته با عملگرهای مقایسه‌ای مثل == و >= آشنا شدیم؟ حاصل این مقایسه‌ها همیشه True یا False بود.
مرور سریع7 == 7 # True age >= 18 # False if age is 15
و می‌تونستیم نتیجه رو داخل متغیر ذخیره کنیمa = 7==7 print(a)
خروجیTrue

حالا سوال اینجاست: بعد از اینکه فهمیدیم یک چیزی True هست یا False، چطور می‌تونیم بر اساسش تصمیم بگیریم؟ اینجاست که if وارد می‌شه! 🚀

🤔 عبارت شرطی if چیه؟

if به پایتون می‌گه: «فقط اگه این شرط درست بود، این کار رو انجام بده». دقیقاً مثل تصمیم‌های روزمره‌ی خودمون: «اگه بارونی بود، چتر بردار».

کدage = int(input("how old are you")) if age > 6: print("you are 6 or more")
خروجی نمونه (وقتی کاربر 9 وارد می‌کنه)how old are you9 you are 6 or more

🔍 قوانین نوشتن if

  • بعد از شرط، حتماً یک دونقطه ( : ) می‌ذاریم.
  • خط بعدی که داخل شرط اجرا می‌شه، باید یک تورفتگی (indent) داشته باشه — یعنی چند فاصله یا یک Tab از سمت چپ فاصله بگیره.
  • اگه شرط False باشه، خط داخل if اصلاً اجرا نمی‌شه.
📐 نکته‌ی مهم درباره‌ی تورفتگی: توی پایتون، تورفتگی فقط یک سلیقه نیست — بخشی از قوانین زبانه! اگه فراموشش کنی، پایتون خطا می‌ده. همیشه بعد از : یک تورفتگی یکسان (معمولاً ۴ فاصله) بذار.
🎯 کجا به کارمون میاد؟ هر بازی، اپلیکیشن یا سایتی که می‌شناسی پر از if هست: «اگه رمز درست بود وارد شو»، «اگه جونت صفر شد بازی تموم شد»، «اگه سبد خرید خالی بود دکمه رو غیرفعال کن».

🌿 if تودرتو (Nested if)

می‌تونیم داخل یک if، یک if دیگه هم بذاریم. به این کار شرط تودرتو می‌گیم.

کدage = int(input("how old are you")) if age == 5: print("you are 5 ") height = int(input("how tall are you? ")) if (height > 140): print("wow! ") elif age == 6: print("you are 6")
خروجی نمونه (سن = 5 و قد = 150)how old are you5 you are 5 how tall are you? 150 wow!

🔍 این کد چیکار می‌کنه؟

  • اول بررسی می‌کنه سن دقیقاً ۵ هست یا نه.
  • اگه بله، وارد بلوک if می‌شه، پیام رو چاپ می‌کنه و بعد یک سوال دیگه می‌پرسه (قد).
  • این سوال جدید داخل یک if دیگه بررسی می‌شه — این همون if تودرتو هست، چون یک شرط داخل شرط دیگه‌ست.
  • اگه سن ۵ نبود ولی ۶ بود، می‌ره سراغ بخش elif.
💡 هر چقدر یک شرط عمیق‌تر (تودرتوتر) بشه، تورفتگیش هم بیشتر می‌شه. برای همینه که مرتب نگه‌داشتن تورفتگی‌ها توی پایتون خیلی مهمه!

🔀 ساختار کامل: if، elif، else

وقتی بیشتر از دو حالت داریم، از elif (مخفف else if) و else استفاده می‌کنیم.

ساختار کلیif condition: # block 1 elif other_condition: # block 2 else: # block 3
بخشکِی اجرا می‌شه؟
ifوقتی شرط اول درست باشه
elifوقتی شرط اول غلط بود ولی این شرط درسته (می‌تونیم چند تا elif پشت‌سرهم بذاریم)
elseوقتی هیچ‌کدوم از شرط‌های بالا درست نبودن

پایتون این بلوک‌ها رو از بالا به پایین بررسی می‌کنه و به محض اینکه یکی از شرط‌ها درست باشه، همون بلوک رو اجرا می‌کنه و از بقیه رد می‌شه.

🎯 مثال از زندگی واقعی: «اگه نمره‌ت بالای ۱۸ بود، عالیه؛ وگرنه اگه بالای ۱۰ بود، قبولی؛ در غیر این صورت، باید بیشتر تلاش کنی.» این دقیقاً همون if / elif / else است!

🌂 مثال‌های تمرینی کلاس

این‌ها مثال‌هایی هستن که توی کلاس با هم روی if کار کردیم:

مثال ۱: چتر لازمه؟

کدis_rainy = False a = 12 b = 12 if(a==b): print("umbrella")
خروجیumbrella

چون a و b هر دو ۱۲ هستن، شرط a==b درست (True) می‌شه و پیام چاپ می‌شه.

مثال ۲: بزرگ یا کوچک؟

کدage = int(input("what is your age?")) if(age>18): print("big") else: print("small")
خروجی نمونه (سن = 15)what is your age?15 small

مثال ۳: زوج یا فرد — این بار با if!

یادته توی جلسه‌ی دوم با % باقی‌مانده رو حساب کردیم؟ حالا می‌تونیم با if مستقیم بگیم زوجه یا فرد!

کدa = int(input("number?")) print(a) if(a%2==0): print("zoog") else: print("fard")
خروجی نمونه (عدد = 8)number?8 8 zoog
💡 مقایسه با جلسه‌ی دوم: قبلاً فقط باقی‌مانده رو چاپ می‌کردیم و خودمون توضیح می‌دادیم «۰ یعنی زوج». حالا با if برنامه خودش تصمیم می‌گیره و مستقیم می‌گه «zoog» یا «fard»!

📓 تکلیف جلسه پنجم

این تمرین‌ها رو توی یک فایل پایتون بنویس و اجرا کن. تمرکز این جلسه روی if، elif و elseست. 💪

۱. رمز عبور ساده

یک رمز عبور رو داخل کد ذخیره کن (مثلاً "python123"). از کاربر با input() رمز بگیر و با if/else بررسی کن که درسته یا نه، و پیام مناسب چاپ کن.

۲. نمره‌ی درسی

یک نمره از کاربر بگیر (بین ۰ تا ۲۰) و با if / elif / else بگو: اگه بالای ۱۸ بود «عالی»، اگه بین ۱۰ تا ۱۸ بود «قبول»، در غیر این صورت «مردود».

۳. رده‌سنی سینما

سن کاربر رو بگیر و با if/elif/else بگو تو کدوم رده‌سنی قرار می‌گیره: زیر ۱۳ سال «کودک»، بین ۱۳ تا ۱۷ سال «نوجوان»، ۱۸ سال به بالا «بزرگسال».

۴. بزرگ‌ترین عدد بین دو عدد

دو عدد از کاربر بگیر و با if/else بگو کدوم بزرگ‌تره. (چالش اضافه: اگه با هم برابر بودن هم پیام جدا بده — نیاز به یک elif داری!)

۵. if تودرتو

سن کاربر رو بگیر. اگه سن دقیقاً ۱۴ بود، یک سوال دوم بپرس: «قدت چند سانتی‌متره؟» و اگه قد بالای ۱۶۰ بود پیام «تو بلندقدترین کلاسی!» رو چاپ کن (شبیه مثال قد و سن که توی کلاس دیدیم).

۶. چالش

یک عدد از کاربر بگیر و با ترکیب if/elif/else و عملگر % بگو که آیا اون عدد هم بر ۲ بخش‌پذیره و هم بر ۳ (در این صورت «بخش‌پذیر بر هر دو»)، فقط بر ۲ («فقط زوج»)، فقط بر ۳ («فقط بر ۳ بخش‌پذیر»)، یا هیچ‌کدوم («هیچ‌کدوم»).
